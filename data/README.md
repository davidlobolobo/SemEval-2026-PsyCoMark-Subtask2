# Data

The data used in this work is the official dataset from SemEval-2026 Task 10 (PsyCoMark), Subtask 2: Conspiracy Detection.

It is not redistributed here. Please obtain it through the official task channels.

- Training set: 4,316 examples (1,541 Yes, 1,990 No, 785 Can't tell)
- Test set: 938 examples (labels withheld)

Examples labeled "Can't tell" were excluded from training.
